# 変更履歴

httptap のすべての注目すべき変更は、リポジトリの [CHANGELOG.md](https://github.com/ozeranskii/httptap/blob/main/CHANGELOG.md) ファイルに文書化されています。

形式は [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) に基づいており、このプロジェクトは [Semantic Versioning](https://semver.org/spec/v2.0.0.html) に準拠しています。

## リンク

- [リポジトリの CHANGELOG.md](https://github.com/ozeranskii/httptap/blob/main/CHANGELOG.md)
- [GitHub Releases](https://github.com/ozeranskii/httptap/releases)

---

*正規の変更履歴はリポジトリで維持され、[git-cliff](https://git-cliff.org/) を使用してリリースワークフローによって自動的に更新されます。*
