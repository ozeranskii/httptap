# Registro de cambios

Todos los cambios notables en httptap están documentados en el archivo
[CHANGELOG.md](https://github.com/ozeranskii/httptap/blob/main/CHANGELOG.md) del repositorio.

El formato se basa en [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
y este proyecto se adhiere al [Versionado Semántico](https://semver.org/spec/v2.0.0.html).

## Enlaces

- [CHANGELOG.md en el repositorio](https://github.com/ozeranskii/httptap/blob/main/CHANGELOG.md)
- [GitHub Releases](https://github.com/ozeranskii/httptap/releases)

---

*El registro de cambios canónico se mantiene en el repositorio y se actualiza automáticamente por el flujo de trabajo de publicación
usando [git-cliff](https://git-cliff.org/).*
